# Portfolio — Elliah Rain Panopio

Personal portfolio site built with [Next.js](https://nextjs.org), React, TypeScript, and Tailwind CSS.

Live: https://portfolio-drab-beta-79.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Editing content

- Projects: `src/data/projects.ts`
- Skills icons: `src/components/Skills.tsx`
- Resume link: put your PDF at `public/resume.pdf`
- Link preview image: `src/app/opengraph-image.tsx`

## Deploy

Pushes to the main branch deploy automatically on [Vercel](https://vercel.com).
